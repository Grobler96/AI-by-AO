# Veo 3 prompt pack: three cinematic launch films

One film each for **SpinPix UK**, **United Sounds (Beaverworks rave)** and **AI by AO**, in the style of the reference reel: photoreal product-launch shots, slow confident camera moves, one glowing brand colour, screens left blank for type, ending on a clean payoff.

Each film is **8 shots**. You generate the clips in Veo 3. I assemble them in Remotion: speed ramps, grade, typography, voice-over, music and sound effects, ending on the end card. Each shot below has the prompt, plus the voice-over line and on-screen text I'll add, so you can see the finished film.

## How to generate (applies to every prompt)

- **Aspect ratio 9:16, 8 seconds, highest quality.** I'll use about 2.5–3.5 s of each clip, so the best moment matters more than the length.
- **Generate 3–4 takes per shot** and keep the best. Camera moves and lighting vary a lot between takes.
- **Keep every prompt's first paragraph (the "look") identical across a film.** That is what makes eight separate clips feel like one production. Each prompt below already has it pasted in; don't trim it.
- **Audio:** each prompt asks for room tone and one small sound effect, with no music and no speech. I'll score and voice the film myself, so please keep the clips' audio too (I'll mix under it where it helps).
- **No text in the clips.** Veo garbles lettering. Every prompt says so, and every screen is blank glow. All words are added afterwards, so they stay crisp and spelled correctly.
- **For smoother cuts**, use Flow's *Frames to Video*: use the last frame of one clip as the first frame of the next where a shot says "(match-cut)". This is how the reference gets its phone → monitor → tablet flow.
- **Send me the clips** named `shot-01.mp4` … `shot-08.mp4` for each film (spinpix / rave / aibyao) and I'll build the film.

If a clip shows text or logos anyway, add "the screen is completely blank" to that prompt and regenerate.
