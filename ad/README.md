# AI by AO brand ad (Remotion)

13-second, 1080x1920 vertical ad built with [Remotion](https://www.remotion.dev). Not part of the website deploy (see `.vercelignore`).

```
cd ad
npm install
npm run studio    # live preview and editing
npm run render    # writes out/aibyao-ad.mp4
```

- `src/Ad.tsx` holds the timeline, copy and scenes. The hook line is the `HOOK` constant at the top.
- `src/theme.ts` holds the brand palette and fonts (bundled in `public/fonts`, so renders work offline).
- Audio: `public/audio/soundtrack.wav` is generated by `audio/make_audio.py` (synthesized music and sound effects, mixed with the voiceover lines in `audio/vo/`, timed to the 13s timeline). Needs `numpy` and `scipy`. The voiceover lines come from `audio/make_voice.py` using the free Kokoro text-to-speech model (`bm_george`, Apache 2.0). To use a recorded or ElevenLabs voice instead, replace `a.wav` to `f.wav` in `audio/vo/` (same lines, similar lengths) and re-run `make_audio.py`.
